# uq notes

Рукописные заметки поверх PDF для Linux/Wayland: страницы PDF, чернила и жесты
живут на GPU, функциональность берётся из зрелых библиотек.

Требования, архитектура и план работ — в `openspec/changes/add-pdf-ink-notes-app/`.

## Зависимости

Arch Linux:

```
pacman -S qt6-base qt6-declarative qt6-wayland qt6-webengine qpdf cmake
```

`qt6-webengine` нужен ради модуля QtPdf — он поставляется именно там.
Для тестов дополнительно: `poppler` (`pdftotext`, `pdftoppm`).

## Сборка и запуск

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build -j$(nproc)
./build/src/uq-notes путь/к/документу.pdf
```

Заметка создаётся рядом с PDF: `документ.uqn`. Исходный PDF не изменяется
никогда. Выбранные толщина и цвет пера хранятся в самой заметке: перо для
конспекта учебника и перо для пометок в статье - разные.

## Установка в систему

Пакет для Arch собирается из этого же дерева:

```
cd packaging && makepkg -f
sudo pacman -U uq-notes-*.pkg.tar.zst
```

После установки `uq notes` появляется в меню приложений, а PDF и файлы `.uqn`
можно открывать через «Открыть с помощью». Тип `application/x-uqnotes` объявлен
наследником SQLite - без этого система опознавала бы заметку как базу данных.

Без пакета то же самое ставится напрямую:

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX=/usr -DUQ_BUILD_TESTS=OFF
cmake --build build -j$(nproc)
sudo cmake --install build
```

Растровые иконки собираются из SVG через `rsvg-convert`, если он есть; без него
ставится только масштабируемая версия.

Пакет собирается с `-DUQ_BUILD_TESTS=OFF -DUQ_DIAGNOSTICS=OFF`: ни тестов, ни
хуков сценарного ввода и снимков экрана в нём нет.

## Тесты

```
cmake -S . -B build && cmake --build build -j$(nproc)
cd build && ctest --output-on-failure
```

Тесты можно отключить при сборке: `-DUQ_BUILD_TESTS=OFF`. Тогда не собираются
ни спайки, ни генератор фикстур - это и делает пакет.

Тестовые PDF (разные форматы страниц и повороты, многоуровневое оглавление с
намеренно битым пунктом, документ на 200 страниц, повреждённый и зашифрованный
файлы) генерируются на этапе сборки в `build/tests/fixtures/`.

## Управление

| Действие | Как |
| --- | --- |
| Писать | перо; левая кнопка мыши |
| Стереть | перевёрнутый конец пера; инструмент «Ластик» |
| Масштаб | pinch двумя пальцами; Ctrl + колесо; кнопки на панели |
| Панорама | один палец (с инерцией); средняя кнопка мыши; колесо |
| Отмена / повтор | Ctrl+Z / Ctrl+Shift+Z |
| Толщина и цвет пера | кнопка ▾ на панели: шесть готовых толщин, ползунок, палитра и произвольный цвет |

Касания пальцем никогда не создают чернил, а пока перо касается экрана, жесты
не начинаются — отсюда и отклонение ладони.

## Переменные окружения

Нужны для измерений и снимков экрана без человека у экрана. В обычной работе
приложение не печатает ничего и не показывает никаких служебных сведений.

`UQ_FRAME_LOG` доступна всегда - это инструментация бюджетов из спеки, без неё
их нечем проверять. Остальные - тестовые леса: они собираются только при
`-DUQ_DIAGNOSTICS=ON` (по умолчанию включено при сборке из исходников, в пакете
выключено).

| Переменная | Что делает |
| --- | --- |
| `UQ_FRAME_LOG=1` | раз в секунду печатает статистику кадров и отдельно каждый кадр длиннее двух кадровых интервалов; заодно показывает сводку в окне |
| `UQ_SCREENSHOT=<путь>` | сохраняет снимок окна и выходит |
| `UQ_SCREENSHOT_DELAY_MS=<мс>` | задержка перед снимком |
| `UQ_GOTO_PAGE=<n>` | перейти на страницу при старте |
| `UQ_DEMO_INK=<сек>` | сценарное письмо: непрерывный поток точек пера |
| `UQ_DEMO_NAV=<сек>` | сценарная навигация: непрерывный зум и быстрая прокрутка |

## Структура

```
packaging/    иконка, ярлык, тип файла .uqn, PKGBUILD
src/canvas/    раскладка документа, холст, зум и панорама, граф сцены
src/ink/       фильтрация и ресемплинг траектории, тесселяция, модель чернил
src/pdf/       документ, асинхронный рендер страниц, оглавление
src/storage/   формат заметки .uqn (SQLite в режиме WAL)
src/export/    экспорт в плоский PDF (overlay + qpdf)
src/perf/      инструментация кадров и латентности
spikes/        прототипы из группы задач 1, результаты — в spikes/FINDINGS.md
tests/         тесты и генератор тестовых PDF
```
